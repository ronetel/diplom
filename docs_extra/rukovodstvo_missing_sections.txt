3.3.X  ВОССТАНОВЛЕНИЕ ПАРОЛЯ
(вставить после раздела 3.3.2 «Регистрация», перед разделом «Гардероб»)
-------------------------------------------------------------------

Для восстановления доступа к учётной записи необходимо на экране входа
нажать ссылку «Забыли пароль?». Откроется экран «Восстановление пароля»
(рисунок 12).

На экране отображается иконка замка, заголовок «Забыли пароль?» и
пояснительный текст. Пользователю необходимо ввести адрес электронной
почты, указанный при регистрации, и нажать кнопку «Отправить код».

Система отправит на указанный адрес письмо с шестизначным кодом
подтверждения и автоматически перейдёт на экран сброса пароля
(рисунок 13).

На экране «Сброс пароля» отображается форма из шести полей для ввода
цифр кода (по одной цифре в каждом поле). Фокус ввода автоматически
переходит между полями при вводе каждой цифры. Ниже расположены два
поля: «Новый пароль» и «Повторите пароль». После заполнения всех полей
необходимо нажать кнопку «Сменить пароль». При успешном выполнении
операции приложение отображает уведомление «Пароль успешно изменён» и
возвращает пользователя на экран входа. В случае истечения срока
действия кода или его некорректного ввода отображается сообщение об
ошибке. Повторно запросить код можно, нажав кнопку «Отправить код
повторно» (доступна через 60 секунд после первой отправки).

ЧТО ДОЛЖНО БЫТЬ НА РИСУНКЕ 12 (forgot_password_page):
  - AppBar с заголовком «Восстановление пароля»
  - Иконка замка по центру
  - Заголовок «Забыли пароль?»
  - Подпись: «Введите email вашего аккаунта — мы отправим код для сброса пароля.»
  - Поле ввода «Email» с иконкой конверта слева
  - Кнопка «Отправить код»

ЧТО ДОЛЖНО БЫТЬ НА РИСУНКЕ 13 (reset_password_page):
  - AppBar с заголовком «Сброс пароля»
  - Иконка замка по центру
  - Заголовок «Введите код из письма»
  - Подпись с email, куда отправлен код
  - 6 квадратных полей по одной цифре
  - Поле «Новый пароль» со значком глаза
  - Поле «Повторите пароль» со значком глаза
  - Кнопка «Сменить пароль»
  - Ссылка «Отправить код повторно»

3.3.X  ЭКРАН РЕКОМЕНДАЦИЙ ПО ПОГОДЕ
(вставить как отдельный раздел — это ГЛАВНЫЙ экран приложения)
Рекомендуется разместить сразу после раздела «Регистрация»/«Вход»,
так как это первый экран после авторизации (главная вкладка).
-------------------------------------------------------------------

Экран «Погода и образы» является главным функциональным экраном
приложения и реализует основную задачу — автоматизированный подбор
одежды с учётом текущих метеорологических условий (рисунок 14).

При открытии экрана приложение автоматически определяет
местоположение пользователя и загружает актуальные данные о погоде
через сервис OpenWeatherMap. В верхней части экрана отображается
карточка с текущей погодой, содержащая: иконку погодного условия,
текущую температуру, название города, описание погоды (например,
«ОБЛАЧНО», «ЯСНО»), а также дополнительные параметры — влажность
воздуха, скорость ветра и процент облачности.

Ниже расположен блок «Что надеть» — список текстовых рекомендаций,
сформированных системой на основании текущей температуры и погодных
условий. Рекомендации могут включать советы о типе одежды, аксессуарах
и слоях одежды.

Основную часть экрана занимает список подходящих образов из гардероба
пользователя с заголовком «Подходящие образы (N)». Для каждого образа
отображается: миниатюра, название, текстовое описание от ИИ, а также
теги — температурный диапазон, уровень утеплённости (холодно /
прохладно / умеренно / тепло / жарко) и тип погоды (солнечно / пасмурно
/ дождь / снег / ветер). При нажатии на карточку образа открывается
экран с его подробным просмотром.

Если часть образов ещё не была проанализирована системой ИИ,
отображается информационный баннер с количеством непроанализированных
образов и кнопкой «Анализировать». После нажатия система отправляет
образы на анализ с использованием модели LLaMA Vision (Groq API) и
через несколько секунд обновляет экран.

Для обновления данных о погоде и рекомендаций необходимо выполнить
жест «потянуть вниз» (pull-to-refresh).

ЧТО ДОЛЖНО БЫТЬ НА РИСУНКЕ 14 (recommend_page):
  - AppBar «Погода и образы» с аватаром пользователя справа
  - Карточка погоды: иконка облака/солнца, крупная температура (+15°C),
    город (Москва), описание погоды, три параметра внизу
    (влажность / ветер / облачность)
  - Карточка «Что надеть» с 2–3 рекомендациями и галочками
  - Список образов: каждый — фото образа, название,
    ИИ-описание, цветные теги (температура, тип погоды)

3.3.X  СОЗДАНИЕ ПУБЛИКАЦИИ
(вставить после раздела «Лента публикаций»)
-------------------------------------------------------------------

Для создания новой публикации в ленте необходимо нажать кнопку «+»,
расположенную в правом нижнем углу экрана ленты. Откроется экран
«Новый пост» (рисунок 15).

На экране расположены: многострочное текстовое поле с подсказкой
«Поделитесь своим образом...» для ввода описания публикации, а также
список сохранённых образов пользователя с возможностью выбора одного
для прикрепления к посту. При выборе образа его карточка выделяется
цветом и отмечается галочкой.

Для публикации необходимо заполнить хотя бы одно из полей: текст или
образ. Кнопка «Опубликовать» расположена в верхней правой части
AppBar. После успешной публикации приложение закрывает экран и
отображает уведомление «Пост опубликован». Публикация проходит
модерацию и отображается в ленте после одобрения модератором.

ЧТО ДОЛЖНО БЫТЬ НА РИСУНКЕ 15 (create_post_page):
  - AppBar «Новый пост» с кнопкой «Опубликовать» справа
  - Многострочное поле для текста (5 строк, с рамкой)
  - Заголовок «Прикрепить образ:»
  - Список карточек образов: миниатюра слева, название и тип события,
    один из образов выделен синим + галочка справа
